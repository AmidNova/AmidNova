## 📂 Featured Projects

### [Wikipedia Pulse — Real-time event detection](https://github.com/AmidNova/wikipedia-pulse)
Pipeline Big Data qui détecte les événements mondiaux émergents en croisant le flux temps réel des éditions Wikipedia avec les pageviews quotidiennes : 365 événements détectés sur 4 808 articles en 5 langues.
*Kafka · PySpark · Airflow · Elasticsearch · Kibana · scikit-learn · Docker Compose*

### [Retail Data Pipeline — End-to-end ELT on GCP](https://github.com/AmidNova/retail-gcp-pipeline)
Pipeline ELT sur GCP : 500 000 transactions chargées dans BigQuery, modélisées avec dbt, orchestrées par Airflow et contrôlées par Soda à chaque couche, avec une étape BigQuery ML (prévision des ventes, segmentation client).
*Airflow · dbt · BigQuery · BigQuery ML · Soda · Docker · GitHub Actions*

### [Kairos — Price Tracker](https://github.com/AmidNova/kairos)
Tracker de prix : scraper FastAPI et Playwright, historique des prix dans PostgreSQL, interface Next.js et alertes par email.
*Next.js · TypeScript · FastAPI · Playwright · PostgreSQL*

### [Bozarts — Artisanal Marketplace](https://github.com/AmidNova/bozarts-v2)
Marketplace déployée sur AWS ECS, infrastructure provisionnée avec Terraform, pipeline CI/CD complet sur GitHub Actions.
*Next.js · TypeScript · PostgreSQL · Docker · Terraform · AWS · GitHub Actions*
